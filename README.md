# Task 2 – To-Do List Web App

## Project title
Build a To-Do List Web App using HTML, CSS and Vanilla JavaScript.

## Objective
Create a front-end task list that allows users to add tasks, mark tasks as complete, and remove tasks.

## Technologies used
- HTML5
- CSS3
- Vanilla JavaScript
- Visual Studio Code
- Google Chrome
- Live Server extension (for local preview)

## Features
- Add a task using the input field and Add Task button.
- Mark a task as complete or undo completion.
- Delete a task.
- Update the task list immediately without reloading the page.
- Responsive layout for smaller screens.

## Files
- `index.html` – page structure.
- `style.css` – page styling and responsive layout.
- `script.js` – task actions and DOM updates.

## How to run
1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click the file and choose **Open with Live Server** (if the extension is installed).
4. Enter a task and select **Add Task**.
5. Use **Complete** to mark it done and **Delete** to remove it.

## Concepts demonstrated
- DOM element selection using `getElementById`.
- Event listeners for form submission and button clicks.
- Dynamic creation of list elements.
- Class updates for completed tasks.
- Event delegation on the task list.
- JavaScript arrays and `const` / `let`.

## Testing checklist
- [ ] Add a task.

- [ ] Mark a task complete.
- [ ] Undo completion.

## Note
This is a front-end-only practice project. Tasks are kept in memory while the page is open; they are not saved after refreshing or closing the page.
